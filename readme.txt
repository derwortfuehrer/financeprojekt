README – Finanzanalyse App (lokale Version)
Herzlich Willkommen!

Dieses Projekt ermöglicht es Ihnen, Aktien, ETFs und Fonds zu analysieren und grafisch auszuwerten.
Diese Version läuft lokal auf Ihrem eigenen Rechner, damit Sie auch sehr große Zeiträume (z.B. 20 Jahre) problemlos verarbeiten können.

🛠️ Voraussetzungen
Ein aktuelles Betriebssystem (Windows, macOS oder Linux)

Python 3.10 oder neuer

Download: https://www.python.org/downloads/

Grundlegende PC-Bedienung (Terminal/Kommandozeile öffnen)

📦 Installation (Schritt für Schritt)
Python installieren, falls noch nicht vorhanden.

Ordnerinhalt auf Ihrem Computer speichern.

Terminal / Kommandozeile öffnen
(unter Windows: CMD oder PowerShell; unter Mac/Linux: Terminal)

In den Projektordner wechseln:

Beispiel für Windows:

bash
Kopieren
cd Pfad\zu\FinanceProjekt
Beispiel für Mac/Linux:

bash
Kopieren
cd /Pfad/zum/FinanceProjekt
(Optional, aber empfohlen) Virtuelle Umgebung erstellen:

Windows:

bash
Kopieren
python -m venv venv
venv\Scripts\activate
macOS/Linux:

bash
Kopieren
python3 -m venv venv
source venv/bin/activate
Benötigte Pakete installieren:

bash
Kopieren
pip install -r requirements.txt
App starten:

bash
Kopieren
python app.py
Browser öffnen und die folgende Adresse eingeben:

cpp
Kopieren
http://127.0.0.1:5000
✅ Jetzt können Sie die App lokal nutzen!

📋 Hinweise
Für umfangreiche Analysen (>10 Jahre Kursdaten) empfehlen wir den lokalen Betrieb.

Die Online-Version auf Render.com ist für kürzere Analysen optimiert (bis zu 1 Jahr).
